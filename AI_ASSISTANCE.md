# AI-Assisted Development Disclosure

Generative AI tools were used as development assistants during parts of this project's implementation, debugging, localization, documentation, and release preparation.

The project requirements and feature direction were provided by the human maintainer. AI-generated suggestions and code were incorporated into the project, then reviewed and tested in selected scenarios. Testing has not covered every Windows configuration, every source model, or every in-game result. The project should therefore be treated as community software that may contain defects.

AI tools are not project maintainers and do not accept, review, or merge contributions. Human maintainers remain responsible for repository decisions and releases. Please report reproducible problems through GitHub Issues and include the tool version, operating system, steps to reproduce, and relevant logs. Remove personal paths and private information before sharing logs.
