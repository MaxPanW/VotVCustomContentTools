# VotV Custom Content Tools

Коллекция независимых пользовательских утилит для подготовки контента для **Voices of the Void**. В репозитории доступны английские и русские версии каждой программы.

## Что делает проект

- **PMX Converter** — преобразует PMX-модели в OBJ/MTL, экспортирует доступные diffuse-текстуры, создаёт конфигурационные файлы принтера и при необходимости добавляет простую коробчатую UCX-коллизию. Есть графический интерфейс и пакетный режим.
- **Poster Generator** — готовит квадратные PNG-постеры 1:1 с прозрачными полями, поворотом и позиционированием, а также необязательной белой окантовкой, текстурой помятости, скотчем и пользовательскими PNG-стикерами.
- **Painting Generator** — подготавливает изображения для четырёх форматов картин: Horizontal (16:9), Square (1:1), Vertical (4:5) и Table (3:4). Программа обнаруживает прозрачность и сохраняет непрозрачные RGB PNG.

Выберите папку языка (`en` или `ru`) внутри каталога нужной утилиты. Каждая языковая папка содержит собственный запускатель, исходный код и инструкцию.

## Чем проект полезен

- Предлагает повторяемый процесс подготовки пользовательских материалов без необходимости открывать отдельный 3D-редактор для базовой конвертации PMX.
- Поддерживает пакетную обработку файлов.
- Помогает сохранять пропорции изображений и готовить файлы под ожидаемые игрой форматы.
- Не изменяет исходные файлы.
- Предупреждает о типичных проблемах, например об отсутствующих текстурах PMX или неподдерживаемой альфа-прозрачности картин.

## Как начать работу

### Требования

- Windows 10 или Windows 11.
- Python 3.9 или новее.
- Pillow. BAT-файлы запуска проверяют наличие Pillow и пытаются установить её через `pip`, если библиотека отсутствует.

### Запуск утилиты

1. Скачайте ZIP репозитория с GitHub или клонируйте репозиторий.
2. Откройте папку нужной утилиты и язык в каталоге `tools/`.
3. Запустите соответствующий `.bat`:
   - PMX Converter: `START_GUI.bat` для работы через окно или `START_CONVERSION.bat` для пакетной обработки.
   - Poster Generator: `START_GENERATOR.bat`.
   - Painting Generator: `START_GENERATOR.bat`.
4. Ознакомьтесь с `README.md` внутри папки утилиты.
5. Перед распространением проверьте результат в игре.

**Важно для PMX:** файл `.pmx` и его текстуры должны находиться в одной папке или в её подпапках, например `Texture2D`. Конвертер ищет текстуры рядом с PMX и во вложенных каталогах, но не во всех остальных папках компьютера.

Перед публикацией удалите из логов личные пути и другие приватные данные. Не загружайте модели, текстуры и другие материалы, если у вас нет разрешения на их распространение.

Перед созданием issue проверьте README конкретной утилиты и поищите похожие обращения.

## Поддержка и вклад участников

Проект поддерживается владельцем репозитория; вклад сообщества приветствуется. Инструкции по сообщениям об ошибках и изменениям находятся в [CONTRIBUTING.md](CONTRIBUTING.md). Английские и русские исходники поддерживаются в отдельных каталогах, поэтому изменения, относящиеся к обеим версиям, следует по возможности переносить в обе.

## Раскрытие использования ИИ

Генеративные ИИ-инструменты использовались как помощники при реализации отдельных частей кода, отладке, локализации, подготовке документации и релизных архивов. Требования определялись владельцем проекта, который также просматривал сгенерированные материалы, однако тестирование ограничено отдельными сценариями и окружениями. Ошибки всё ещё возможны; сообщайте о воспроизводимых проблемах и проверяйте результат в игре.
