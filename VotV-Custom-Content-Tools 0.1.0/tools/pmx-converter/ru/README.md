VOTV PMX CONVERTER — КРАТКАЯ ИНСТРУКЦИЯ
======================================

Графический интерфейс
---------------------
1. Запустите START_GUI.bat.
2. Нажмите «Добавить PMX-файлы…» и выберите исходные модели.
3. Задайте необязательное имя, целевую высоту или коэффициент масштаба.
4. Выберите размер текстур и параметры коробчатой коллизии UCX.
5. Укажите папку результата и нажмите «КОНВЕРТИРОВАТЬ».
6. Проверьте журнал и протестируйте готовую модель в игре.

Пакетная обработка
------------------
Поместите файлы в папку input и запустите START_CONVERSION.bat. Без аргументов
программа рекурсивно обрабатывает PMX в input. Для отдельной обработки можно
перетащить PMX-файлы на BAT-файл. Настройки пакетного режима находятся в settings.json;
переопределения для конкретных файлов указываются в models.csv.

Текстуры — важно
----------------
Храните PMX и его текстуры вместе: в одной папке или в соответствующих подпапках
(например, Texture2D). Конвертер ищет текстуры в папке PMX и её подпапках, но не ищет
в произвольных каталогах за их пределами. Не переносите PMX отдельно от текстур.
Если текстуры не найдены, часть материалов может экспортироваться без текстурной карты.

Результат
---------
Конвертер создаёт папку модели с OBJ, MTL, доступными diffuse-текстурами, icon.png
и properties.cfg. При включённой настройке UCX добавляется отдельный низкополигональный
коробчатый коллайдер. Анимация, скелет и динамическая физика PMX не переносятся.

Требования
----------
Windows 10/11, Python 3.9+ и библиотека Pillow. BAT-файлы проверяют наличие Pillow и
при необходимости пытаются установить её через pip. Blender и MMD Tools не требуются.

## Интерфейс
Графическое окно оформлено в стилистике компьютерного интерфейса Voices of the Void: тёмный фон, контрастные жёлтые акценты и цветовые состояния для основных, опасных и информационных действий. Для оформления используется общий модуль `votv_theme.py`, который должен находиться рядом с файлами программы.
