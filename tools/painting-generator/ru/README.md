VOTV PAINTING GENERATOR
=======================

Назначение
----------
Утилита подготавливает изображения для четырёх типов пользовательских картин
Voices of the Void. Поддерживаются пакетная обработка, предпросмотр, выбор разрешения,
изменение пропорций и заполнение областей, которые были прозрачными в исходнике.

Запуск
------
1. Распакуйте архив в отдельную папку.
2. Запустите START_GENERATOR.bat.
3. Нажмите «Добавить» и выберите одно или несколько изображений.
4. Выберите тип картины, разрешение и способ изменения размера.
5. При необходимости задайте цвет для заполнения прозрачных областей.
6. Проверьте предпросмотр и нажмите «ПОДГОТОВИТЬ КАРТИНЫ».

При отсутствии Pillow BAT-файл попробует установить библиотеку через pip. Требуется
Python 3.9 или новее.

Типы картин
-----------
- Horizontal — 16:9; каталог: %LOCALAPPDATA%\VotV\Assets\paintings\h
- Square — 1:1; каталог: %LOCALAPPDATA%\VotV\Assets\paintings\s
- Vertical — 4:5; каталог: %LOCALAPPDATA%\VotV\Assets\paintings\v
- Table — 3:4; каталог: %LOCALAPPDATA%\VotV\Assets\paintings\t

Способы изменения размера
-------------------------
- «Растянуть»: заполняет целевой размер полностью, но может изменить пропорции исходника.
- «Вписать (без обрезки)»: сохраняет пропорции и показывает всё изображение; свободные
  области заполняются выбранным цветом.
- «Заполнить (обрезать края)»: сохраняет пропорции и заполняет целевой формат, обрезая
  части изображения, выходящие за его границы.

Разрешение
----------
Доступны режимы «Авто (по исходнику)», 512, 1024 и 2048 пикселей по длинной стороне.
Для фиксированных размеров второе измерение рассчитывается автоматически исходя из
выбранного соотношения сторон.

Обработка прозрачности
----------------------
Картины сохраняются как RGB PNG без альфа-канала. Если в выбранных исходниках обнаружены
прозрачные пиксели, перед обработкой появляется предупреждение. Прозрачные области
сводятся с выбранным непрозрачным цветом; по умолчанию используется белый. Цвет можно
изменить кнопкой «Выбрать…». Исходные файлы не изменяются.

Папка результата
----------------
По умолчанию каталог определяется выбранным типом картины. Поле пути можно изменить
вручную, выбрать другую папку кнопкой «Обзор…» или восстановить стандартный путь кнопкой
«Папка VotV».

Выходные PNG получают суффикс _votv. Существующие файлы не перезаписываются: при
совпадении имени программа добавляет числовой суффикс.

Ограничения
-----------
Утилита изменяет размер и формат уже существующих изображений; она не генерирует новый
визуальный контент и не выполняет художественную ретушь.

## Интерфейс
Графическое окно использует тему, вдохновлённую компьютерным интерфейсом Voices of the Void: чёрные панели, жёлтые контуры и компактные элементы управления. Файл `votv_theme.py` должен находиться рядом с `painting_generator.py`.
